## Партнёрский навык: Хранитель эха
Можно оседлать для передвижения по воздуху. Можно призвать на базе только одного. Пока находится на базе, постоянно патрулирует воздушное пространство над базой и при появлении нарушителей атакует их артиллерийским огнём с большой высоты. level value 1 MainValue 1.1 Пробуждение : 2 MainValue 1.3 Пробуждение : (Увеличение урона: Небольшое ) 3 MainValue 1.6 Пробуждение : (Увеличение урона: Среднее ) 4 MainValue 2 Пробуждение : (Увеличение урона: Большое ) 5 MainValue 2.5 Пробуждение : (Увеличение урона: Очень большое )
