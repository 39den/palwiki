=== "Обзор"

    #### Работа на базе
    - Разжигание огня — ур. 1
    - Ручная работа — ур. 1
    - Рубка деревьев — ур. 1
    - Транспортировка — ур. 1


    #### Партнёрский навык: Весёлая пальба
    При активации Танзи Игнис в течение некоторого времени ведёт огонь по ближайшим врагам из штурмовой винтовки Огонь . Технологии 13 level value 1 MainValue 30 Пробуждение : 2 MainValue 32 Пробуждение : (Увеличение урона: Небольшое ) 3 MainValue 36 Пробуждение : (Увеличение урона: Среднее ) 4 MainValue 42 Пробуждение : (Увеличение урона: Большое ) 5 MainValue 50 Пробуждение : (Увеличение урона: Очень большое )


    #### Чем хорош / чем плох
    - ✅ можно оседлать
    - ❌ слабая атака (75); разводится только особой парой

    > Ладони эволюционировали так, чтобы можно было хватать раскалённое, не обжигаясь. Если закончатся патроны, можно схватить разогретый ствол и пойти врукопашную.
