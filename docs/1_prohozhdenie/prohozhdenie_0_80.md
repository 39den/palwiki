# Прохождение от 0 до 80 уровня (пошагово)

Это «маршрут» по игре. Делай отрезки по порядку. Уровни примерные: если трудно — пофарми ещё пару уровней.
Технологии: в каждом отрезке ниже есть список **всего, что открывается** (из данных игры). Очки технологий копи на главное (сферы, станки, броню).
Имена палов: русское (английское, где и на каком уровне они бывают в дикой природе по данным игры).

## Уровни 0–5: Выжить и поймать первых палов
- 🗺️ **Куда идти:** Стартовая зона — Ветреные холмы (Windswept Hills)<span class="unv" title="Ещё перепроверяется">ⓘ</span>. Не уходи далеко: враги вокруг ур. 1–5.
- 🐾 **Кого ловить:** Ламболл (Lamball, дикие ур. 1–3), Каттива (Cattiva, дикие ур. 1–3), Чикипи (Chikipi, дикие ур. 1–3), Лифманк (Lifmunk, дикие ур. 1–3), Фокспаркс (Foxparks, дикие ур. 5–7) (огонь — нужен для костра и печи), Пенгуллет (Pengullet, дикие ур. 1–10) (вода — полив), Танзи (Tanzee, дикие ур. 4–6), Депрессо (Depresso, дикие ур. 4–7).
- 🔨 **Что сделать:** Примитивный верстак → Пал-сферы (много! 20–30 шт.), Каменный топор и кирка, Костёр, Деревянный сундук, Палбокс (Контейнер для Палов), Простая кровать, Соломенная кровать для палов, Ягодная плантация, Кормушка.
- 👹 **Боссы:** Первые альфы в зоне (большие светящиеся палы) — пока НЕ трогай, если у них ур. 10+.
- 📊 **Очки статов:** Здоровье и выносливость (бегать и не умирать).
- 🛡️ **Снаряжение:** Старый лук и стрелы, деревянная дубинка, тканая одежда.
- ✅ **Готов к следующему этапу, если:** уровень ≥ 5, в отряде 4–5 палов не ниже ур. 1, есть 20+ сфер текущего уровня, броня этого этапа и запас лечилок; босс этого этапа побеждён.
- 🐾 **Если играешь палами:** держи 2 бойцов разных стихий + щит/лечение; вкладывай очки в HP/выносливость; улучшай бойцов душами и конденсацией по мере сил.
- 📜 **Все технологии этого отрезка:**
  - ур.1: Примитивный верстак, Каменный топор, Каменная кирка, Переносной факел, Деревянная дубинка
  - ур.2: Контейнер для Палов, Пал-сфера, Костер, Деревянный сундук, Ремонтный стол, Набор для строительства: дерево, Устройство для преображения Палов
  - ур.3: Старый лук, Стрела, Каменное копьё, Простая кровать, Соломенная кровать для Палов, Глобальный Палбокс
  - ур.4: Обыкновенный щит, Тканая одежда, Ткань, Кормушка

## Уровни 5–10: Нормальная база и первые ездовые
- 🗺️ **Куда идти:** Исследуй холмы, открывай статуи быстрого перемещения (большие каменные статуи — Статуя Орлана<span class="unv" title="Ещё перепроверяется">ⓘ</span>). Ищи голубой палдиум у рек.
- 🐾 **Кого ловить:** Рашоа (Rushoar, дикие ур. 5–7) (первый ездовой), Викси (Vixy, дикие ур. 1–3) (копает сферы и предметы на пастбище), Даэдрим (Daedream, дикие ур. 4–7), Хукрат (Hoocrates, дикие ур. 4–7), Джолтхог (Jolthog, дикие ур. 4–8) (молния — генератор позже), Дайэхаул (Direhowl, дикие ур. 10–11) (быстрый ездовой).
- 🔨 **Что сделать:** Пастбище для скота (Ranch) → Ламболл даёт шерсть, Чикипи — яйца. Ткань, Лесопилка/Карьер (по мере открытия), Седло Рашоа, Верстак снаряжения для палов, Монумент Силы (Statue of Power) с ур. 9.
- 👹 **Боссы:** Первая башня — Зои и Гриззболт (ур. 10). Можно попробовать к ур. 10–12, если есть 5–6 палов ур. 10+.
- 📊 **Очки статов:** Вес (+больше носить) и здоровье.
- 🛡️ **Снаряжение:** Трёхзарядный лук, Обыкновенный щит, Меховая броня (если холодно).
- ✅ **Готов к следующему этапу, если:** уровень ≥ 10, в отряде 4–5 палов не ниже ур. 5, есть 20+ сфер текущего уровня, броня этого этапа и запас лечилок; босс этого этапа побеждён.
- 🐾 **Если играешь палами:** держи 2 бойцов разных стихий + щит/лечение; вкладывай очки в HP/выносливость; улучшай бойцов душами и конденсацией по мере сил.
- 📜 **Все технологии этого отрезка:**
  - ур.5: Ягодная плантация, Пастбище для скота, Стандартный парашют, Набор деревянной мебели для гостиной, Набор деревянной мебели для трактира, Набор мебели для хранения в трактире
  - ур.6: Верстак снаряж-я для Палов, Огненная стрела, Стационарный факел, Вывеска, Настенная вывеска, Седло Рашоа, Шлейка Фокспаркса, Набор декоративных растений
  - ур.7: Вышка надзирателя, Бита, Лесопилка, Карьер, Мешок с песком, Сигнальный колокол, Седло Мелпаки, Набор настенных декоративных растений
  - ур.8: Дробилка, Ядовитая стрела, Деревянная защитная стена, Деревянные ворота, Подвесная ловушка, Набор каминов
  - ур.9: Монумент Силы, Маленький мешочек с кормом, Тропическая одежда, Тундровая одежда, Горячий источник, Шлейка с седлом для Дайэхаула, Набор ковров

## Уровни 10–15: Первая башня и металл
- 🗺️ **Куда идти:** Металлическая руда — серые камни с рыжими прожилками в горах. Ищи сундуки и лагеря врагов.
- 🐾 **Кого ловить:** Иктирдир (Eikthyrdeer, дикие ур. 9–11) (рубит деревья + ездовой), Томбат (Tombat, дикие ур. 12–14), Найтвинг (Nitewing, дикие ур. 12–13) (первый летающий ездовой), Мау (Mau), Гумосс (Gumoss, дикие ур. 2–4), Робинквилл (Robinquill, дикие ур. 30–34).
- 🔨 **Что сделать:** Примитивная печь → Металлический слиток. Металлические топор и кирка (ур. 11), Инкубатор, Качественный верстак, Пистолет-пулемёт Лифманка / Штурмовая винтовка Танзи (ур. 12), Пистолет с крюком (ур. 12–13, тянет на скалы).
- 👹 **Боссы:** БАШНЯ 1: Зои и Гриззболт (Normal ур. 10, HP 12 900). Гриззболт — молния → бери земляных палов (Дигтос<span class="unv" title="Ещё перепроверяется">ⓘ</span>, Рашоа).
- 📊 **Очки статов:** Здоровье, вес. Можно 1–2 очка в атаку, если любишь стрелять.
- 🛡️ **Снаряжение:** Меховая броня, металлическое оружие ближнего боя.
- ✅ **Готов к следующему этапу, если:** уровень ≥ 15, в отряде 4–5 палов не ниже ур. 10, есть 20+ сфер текущего уровня, броня этого этапа и запас лечилок; босс этого этапа побеждён.
- 🐾 **Если играешь палами:** держи 2 бойцов разных стихий + щит/лечение; вкладывай очки в HP/выносливость; улучшай бойцов душами и конденсацией по мере сил.
- 📜 **Все технологии этого отрезка:**
  - ур.10: Примитивная печь, Трехзарядный лук, Украшение для волос с перьями, Гвоздь, Лестница, Небольшой капкан, Набор антикварной мебели для хранения, Инкубатор
  - ур.11: Металлический топор, Металлическая кирка, Качественный верстак, Набор флагов Браконьеров, Седло Чиллета, Пистолет-пулемёт Лифманка, Набор антикварных стульев
  - ур.12: Меховая броня, Нож для разделки мяса, Средневековый стол фармацевта, Штурмовая винтовка Танзи, Седло Иктирдира, Набор моделей деревьев, Набор аккуратной столовой мебели, Пистолет с крюком
  - ур.13: Арбалет, Металлическое копьё, Металлический сундук, Термоконтейнер, Потрепанное чучело, Штурмовая винтовка Танзи Игнис, Набор антикварных шкафов для хранения
  - ур.14: Мегасфера, Сферическая Мастерская, Средний мешочек с кормом, Настенный факел, Седло Юнивольта, Набор моделей осенних деревьев, Набор антикварных столов, Капсула с эссенцией Пала

## Уровни 15–20: Разведение и холод/жар
- 🗺️ **Куда идти:** Иди в лес и к пустыне/снегам по краям. Готовь тёплую/прохладную одежду.
- 🐾 **Кого ловить:** Пенкинг (Penking, дикие ур. 20–23) (лёд/вода, добыча), Моссанда (Mossanda, дикие ур. 32–36) (сильный ездовой), Келпси (Kelpsea, дикие ур. 1–10), Селарай (Celaray, дикие ур. 1–10) (глайдер), Юнивольт (Univolt, дикие ур. 20–24), Свипа (Sweepa, дикие ур. 25–28), Мелпака (Melpaca, дикие ур. 5–7).

- 👹 **Боссы:** БАШНЯ 2: Лили и Лилин (ур. 20, HP 42 500). Лилин — трава/нейтральный → огонь бьёт траву: Фокспаркс, Арсокс.
- 📊 **Очки статов:** Здоровье, выносливость, вес.
- 🛡️ **Снаряжение:** Мушкет/Штурмовая винтовка, металлическая броня.
- ✅ **Готов к следующему этапу, если:** уровень ≥ 20, в отряде 4–5 палов не ниже ур. 15, есть 20+ сфер текущего уровня, броня этого этапа и запас лечилок; босс этого этапа побеждён.

- 📜 **Все технологии этого отрезка:**
  - ур.15: Начальный набор для рыбалки, Пшеничная плантация, Мельница, Деревянная доска, Клетка для демонстрации, Седло Арсокса, Седло Найтвинга, Поясной фонарь

  - ур.18: Мегаглайдер, Морозостойкая меховая броня, Кулер, Перчатки Токотоко, Ракетомёт Пенгуллет Лакс, Набор для ванной, Набор изысканной антикварной мебели, Кольцо сдерживания

## Уровни 20–25: Сферы посильнее и электричество
- 🗺️ **Куда идти:** Пещеры (подземелья) появляются и исчезают — значок на карте. В них сундуки и боссы.
- 🐾 **Кого ловить:** Анубис (Anubis) (Ручная работа 4 — лучший крафтер ранней игры, альфа в пустыне), Гриззболт (Grizzbolt), Диноссум (Dinossom, дикие ур. 25–28), Ванвирм (Vanwyrm, дикие ур. 20–25), Бигард (Beegarde, дикие ур. 28–33), Элизаби (Elizabee, дикие ур. 34–38), Виксен (Wixen, дикие ур. 23–27).
- 🔨 **Что сделать:** Гигасфера (ур. 20), Генератор электричества (нужен пал-электрик), Фабрика/конвейер, Улучшенная печь, Холодильник (еда не портится).
- 👹 **Боссы:** Альфы ур. 20–30 в лесу и у реки. Бэллануар (рейд ур. 35) — пока рано.
- 📊 **Очки статов:** Здоровье ×2 очка за каждое в другом — держи баланс.
- 🛡️ **Снаряжение:** Двуствольный дробовик, Ракетница — ближе к 30.
- ✅ **Готов к следующему этапу, если:** уровень ≥ 25, в отряде 4–5 палов не ниже ур. 20, есть 20+ сфер текущего уровня, броня этого этапа и запас лечилок; босс этого этапа побеждён.
- 🐾 **Если играешь палами:** держи 2 бойцов разных стихий + щит/лечение; вкладывай очки в HP/выносливость; улучшай бойцов душами и конденсацией по мере сил.
- 📜 **Все технологии этого отрезка:**
  - ур.20: Гигасфера, Оружейная мастерская, Большой ящик инструментов, Набор флагов Организации по Защите Палов, Седло Элфидрана, Седло Тарантрисса, Седло Свипы, Набор антикварных диванов, Многомерное хранилище Палов
  - ур.21: Мушкет, Порох, Грубые патроны, Томатная плантация, Священный огонь, Большой капкан, Седло Ванвирма, Седло Иктирдира Тэрра, Антикварный туалетный столик
  - ур.22: Центр экспедиций Палов, Электродубинка, Качественная приманка, Рынок предметов, Рынок Палов, Седло Ванвирм Криста, Набор часов, Набор металлических столов и стульев, Грозовое облако возвращения
  - ур.23: Металлическая броня, Металлический шлем, Модуль дуги, Большой мешочек с кормом, Фонтан, Седло Кингпака, Набор моделей бамбука, Набор контейнеров для хранения, Набор для строительства на воде
  - ур.24: Самодельный пистолет, Мягкая кровать для Палов, Шкафчик для лекарств, Клиника, Клумба, Шлейка Фокспаркс Криста, Седло Азуроба, Седло Диноссума, Рудник

## Уровни 70–75: Сложные башни и ультра-рейды
- 🗺️ **Куда идти:** Мировое Древо: собирай Древнюю кору, сияющие самоцветы для Пробуждения.
- 🐾 **Кого ловить:** Мутанты, идеальные палы с 4 пассивками.
- 🔨 **Что сделать:** Древняя броня/шлем/щит (ур. 70–71), Тяжёлая штурмовая винтовка, Лазерный меч (ур. 73), Специальный торт (ур. 74).

- 🛡️ **Снаряжение:** Ботинки тройного прыжка (ур. 71).
