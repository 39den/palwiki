# Благородный

<div class="psv-hero" markdown="0"><span class="psv r-3 big">Благородный</span> <span class="rk">Ранг 3 · редкая</span><div class="en">Noble</div></div>

**Что даёт:** Цена продажи предметов увеличена на +5%

Полезная пассивка. Одинаковые пассивки на одном пале не складываются.

## Где взять

- 🧬 **Разведение:** передаётся от родителей детям (шанс выше, если пассивка у обоих).
- 🏥 **Операционный стол:** ставится за 50 000 золота (открывается после победы на арене).
