# Крупная рыбка

<div class="psv-hero" markdown="0"><span class="psv r-3 big">Крупная рыбка</span> <span class="rk">Ранг 3 · редкая</span><div class="en">Whopper</div></div>

**Что даёт:** Увеличение водного урона на 5%; Увеличение ледяного урона на 5%; Защита +5%

Полезная пассивка. Одинаковые пассивки на одном пале не складываются.

## Где взять

- 🧬 **Разведение:** передаётся от родителей детям (шанс выше, если пассивка у обоих).
