# Как сделать пала сильнее (все способы)

Порядок: Пассивки → Пробуждение → Конденсация (звёзды) → Души → Уровень 80 → Скрытые таланты.

## 1. Уровень пала
- Пал растёт в отряде и на базе (на базе медленнее<span class="unv" title="Ещё перепроверяется">ⓘ</span>). Максимум — уровень игрока? Нет: максимум 80<span class="unv" title="Ещё перепроверяется">ⓘ</span>. Опыт: бои, книги/предметы опыта.
- В 1.0 палы низкого уровня растут быстрее<span class="unv" title="Ещё перепроверяется">ⓘ</span>.

## 2. Конденсация (звёзды ранга)
- Постройка **Капсула с эссенцией Пала** (Pal Essence Condenser), ур. 14.
- Кладёшь одинаковых палов → основной получает звезду.
- В 1.0: **4 → 8 → 12 → 24** = 48 палов до 4 звёзд (раньше 116)<span class="unv" title="Ещё перепроверяется">ⓘ</span>.
- Каждая звезда: +5% HP, атаки, защиты<span class="unv" title="Ещё перепроверяется">ⓘ</span>, усиливает партнёрский навык (уровень навыка = звезда+1).
- На 4 звёздах: **+1 ко всем пригодностям работы**.
- Можно класть палов с пассивками — в 1.0 часть пассивок переносится при конденсации<span class="unv" title="Ещё перепроверяется">ⓘ</span>.

## 3. Души палов и Монумент Силы
- **Души**: Маленькая, Средняя, Большая, Абсолютная (Small/Medium/Large/Ultimate Pal Soul).
- На Монументе Силы улучшаешь палу HP/Атаку/Защиту/Скорость работы — до **20 шагов** каждого.
 Цена шагов: 1–4 Маленьких → 1–3 Средних → 1–3 Больших → 1–4 Абсолютных.
- Где брать души: подземелья, сундуки, экспедиции, боссы. См. «Предметы → Материалы → … душа Пала».

## 4. Пробуждение (1.0, Awakening)
- Новая механика 1.0. Нужны **сияющие самоцветы** (Radiant Gems) из Мирового Древа<span class="unv" title="Ещё перепроверяется">ⓘ</span>.
- Даёт палу новый уровень силы (бонус к навыкам/статам)<span class="unv" title="Ещё перепроверяется">ⓘ</span>.

## 5. Мутации
- Особые яйца. Пал-мутант: другой вид, IV 90–100, альфа, 2 звезды, 2–4 радужные пассивки (Бессмертие, Особая конституция, Нянька, Тяжёлая броня, Небесное скольжение).
- Мутационные пассивки наследуются разведением.
- Есть **Одноразовые импланты** (Disposable Implant) — вставляют мутационную пассивку на Операционном столе.

## 6. Операционный стол
- Меняет/добавляет пассивки за **импланты** (Implant). Импланты покупаются/выпадают [см. «Справочник → Операционный стол»].

## 7. Плоды навыков
- Учат палу активный навык нужной стихии. Растут на деревьях-плодах по миру и на «Плантации плодов мастерства» (ур. 71).
- Пал держит 3 активных навыка в бою, остальные хранит.

## 8. Скрытые таланты
- У каждого пала 3 скрытых числа 0–100: **HP, Атака, Защита**.
- Каждый талант добавляет до **+30%** к стату<span class="unv" title="Ещё перепроверяется">ⓘ</span>.
- Видно через Очки укротителя палов (или калькулятор IV).
- Альфы и мутанты имеют высокие таланты.

## Формула (упрощённо)
Итоговый стат ≈ База(уровень, вид) × (1 + талант%) × (1 + пассивки%) × (1 + звёзды%) × (1 + души%)<span class="unv" title="Ещё перепроверяется">ⓘ</span>.
