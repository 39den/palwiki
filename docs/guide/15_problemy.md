# Баги и проблемы: что делать

| Проблема | Что сделать |
|---|---|
| Не могу зайти на сервер | Одинаковая версия у всех и у сервера; порт UDP 8211 открыт; пароль верный |
| «Version mismatch» | Обнови игру и сервер (SteamCMD `app_update 2394010`) |
| Пал застрял в текстурах | Убери в Палбокс и выпусти снова; в игре есть пункт «Если вы застряли» (Esc → «Застрял» [проверить]) |
| Сам застрял | Esc → кнопка возврата/телепорт на базу [проверить], или телепорт к статуе |
| Палы не работают | Проверь: в зоне базы? есть станок/ресурс? не голодны? рассудок? пригодность нужная? приоритет работы? |
| Палы не едят | Еда в Кормушке, не испорчена; кормушка в зоне базы |
| Палы болеют/депрессия | Лекарства, горячий источник, кровати, еда |
| Яйцо не появляется | Нужен торт и палы разного пола |
| Лаги на сервере | Меньше палов на базе, меньше предметов на земле (`DropItemMaxNum`), перезагрузка сервера раз в день |
| Сломался сейв | Восстанови из папки backup (сначала выключи сервер!) |
| Пропали вещи после смерти | Вернись к сумке на месте смерти; `DeathPenalty` |
| Сфера пролетает мимо | Модуль самонаведения / статуи Лунариса |
| Не открывается технология | Нужен уровень и очки; древние — за очки древних технологий |
| Мод сломал игру | Удали моды, проверь целостность файлов Steam |
