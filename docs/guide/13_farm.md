# Фарм и лут: где брать всё

## Как пользоваться
- Любой предмет ищи в боте или в «Предметы»: в карточке есть **Как получить** (крафт 🔨, палы 🐾, люди/боссы 👤, торговец 🛒, сундуки/награды 📦) и **Нужен для**.
- Дроп каждого пала — в его карточке («Что выпадает» и «Дроп с альфы»).

## Палы и пассивки для фарма
- <a class="psv r-4" data-psv="Щедрость" href="../../passivki/lavish_hospitality/">Щедрость</a> — дроп с этого пала ×2 (+100%). <a class="psv r-3" data-psv="Дух радушия" href="../../passivki/service_minded/">Дух радушия</a> — +50%.
- <a class="psv r-3" data-psv="Начальник рудника" href="../../passivki/mine_foreman/">Начальник рудника</a> (+25% добычи игрока), <a class="psv r-3" data-psv="Лидер лесозаготовок" href="../../passivki/logging_foreman/">Лидер лесозаготовок</a> (+25% рубки игрока), <a class="psv r-3" data-psv="Мотиватор" href="../../passivki/motivational_leader/">Мотиватор</a> (+25% работы игрока) — пока пал в отряде.
- Палы, снижающие вес ресурсов — «Справочник → Палы, увеличивающие вес».
- Сервер: `CollectionDropRate`, `EnemyDropItemRate` — множители.

## Маршруты (простые)
1. **Утро на базе**: собери продукцию, положи еду в кормушку, проверь рассудок палов.
2. **Альфа-круг**: облети альф своего уровня (значки на карте) → Детали древней цивилизации + чертежи.
3. **Подземелья**: заходи во все открытые входы по пути — души, ключи, плиты.
4. **Экспедиции** отправляй всегда перед выходом.
5. **Ящики снабжения** — лети к значку.

## Шансы чертежей
Чертежи 1–4 уровня (1★–4★) выпадают с убывающим шансом. Пример (подземелья холмов): 1★ ~1.7–2.5%, 2★ ~0.3–0.5%, 3★ ~0.05–0.1%, 4★ ~0.01–0.02%. Полные таблицы — «Справочник → Подземелья» и «Таблицы лута».
