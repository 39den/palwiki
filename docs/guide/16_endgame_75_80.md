# Эндгейм 75–80: как стать сильнее (бой палами)

## Начни здесь (5 шагов)
1. Сделай копию сохранения на сервере. Это запасная копия мира. Если что-то пойдёт не так, ты всё вернёшь.
2. Выпей Снадобье очистки памяти. Оно возвращает все очки, которые ты вложил в персонажа. Вложи их заново по таблице из раздела «Куда вкладывать очки».
3. Возьми в отряд Силвегиса и Петаллию (или Лилин). Первый бережёт твой щит, вторая тебя лечит.
4. Выбери 1–2 сильных бойца из раздела «Кто лучше всех дерётся».
5. Улучшай бойцов по порядку из раздела «Как сделать пала сильнее».

Игра: Palworld из Steam, версия 1.0.5 (вышла 14 сентября 2026). Самый высокий уровень игрока — 80.
Названия даны как в русской версии игры. В скобках — английское название, чтобы было легко искать.

## Главная идея
Ты — командир. Ты не бьёшь сам. Ты выживаешь, лечишься, держишь щит и показываешь палу, кого бить. Бьют палы.
Почему так: в версии 1.0 палы стали бить очень сильно. А твоя атака усиливает только твоё оружие.

Здоровье — чтобы тебя не убили одним ударом. Выносливость — чтобы долго бегать и уворачиваться. Вес — чтобы унести больше.
Снадобье очистки памяти сбрасывает только очки, которые ты вложил сам. На палов оно не действует.

## Что надеть
### Броня и полёт
- Древний шлем, Древняя броня, Древний щит. Это лучшая защита.
- Крылатый ранец — летать.
### Украшения (аксессуары)
- Скипетр стихии твоих палов (например, Скипетр Ледяного Императора для ледяных палов). Он усиливает палов этой стихии. Точные цифры смотри в игре.
- Очки укротителя Палов. Твои удары не добивают врага: у него остаётся 1 здоровья. Удобно, чтобы ловить. Ещё показывают скрытые силы палов. Делаются из 15 Древней коры.
- Пояс для инструментов жителя острова — больше вес и скорость работы. Из 30 Древней коры.
- Кольца защиты от стихии — надевай против нужного босса.
### Оружие (только помочь)
- Дрономёт. Дроны стреляют сами. Ты в это время уворачиваешься.
- Тяжёлая штурмовая винтовка — если в отряде Орсерк (смотри ниже).

### Готовые наборы (4 пассивки)
1. Для всего: Легенда + Демон-бог + Хладнокровный + Бессмертие.
2. Для рейдов: Легенда + Алмазное тело + Бессмертие + Хладнокровный.
3. Быстро убить (башни): Обоюдоострый святой меч + Бог разрушения + Демон-бог + Хладнокровный.
4. Дёшево: Свирепый + Мистер мускул + Легенда + Хладнокровный.
5. Для танка (пал, который принимает удары): Алмазное тело + Особая конституция + Легенда + Мастер обороны.

## Как сделать пала сильнее
Делай по порядку.
1. Пассивки. Сначала дай палу хорошие пассивки (смотри наборы выше).
2. Пробуждение. Найди сияющие самоцветы в глубине Мирового Древа. Отдай их палу. RU-название самоцветов.
3. Конденсация. Положи пала в Капсулу с эссенцией Пала. Нужно 48 таких же палов: 4, потом 8, потом 12, потом 24. Каждая звезда даёт +5% к здоровью, атаке и защите (максимум +20%) и усиливает партнёрский навык.
4. Души Пала. Неси их к Монументу Силы. Бойцу — атака и здоровье. Танку — здоровье и защита.
5. Уровень 80. Палов можно быстро поднять книгами опыта.

### Разведение (как получить нужные пассивки)
1. Найди двух палов. У каждого есть нужные тебе пассивки, а лишних нет.
2. Посади их на Пастбище свиданий.
3. Положи туда Торт. Без торта яиц не будет.
4. Вылупи яйцо в инкубаторе. Посмотри пассивки малыша.
5. Повторяй, пока не будет пал с 4 нужными пассивками.
Совет: пассивка <a class="psv r-3" data-psv="Филантроп" href="../../passivki/philanthropist/">Филантроп</a> на родителе делает яйца в 2 раза быстрее.
Мутации (Бессмертие, Особая конституция) — дело удачи. Просто выводи много яиц.
Ещё пассивку можно вставить через Операционный стол для Палов с помощью импланта.

## Команды для каждого дела
### Рейды
Рейд вызывают на Алтаре для призыва с помощью плиты (особый предмет).
Как делить роли на 4 игроков:
- 2 игрока — главные бойцы (палы против стихии босса).
- 1 игрок — щит и лечение (Силвегис, Петаллия).
- 1 игрок — баффы (Орсерк и винтовка).

### Башни
- Сложный режим, есть 5 минут.
- На бойце: набор «Быстро убить».
- В отряде: Силвегис.

### Альфы и подземелья
- Джетрагон (летает и сильно бьёт), Фросталлион, Петаллия.
- Набор пассивок «Для всего».

### Защита базы
- Оставь на базе пару сильных боевых палов.
- Поставь оборонные постройки.

## Фарм (сбор ресурсов)
1. Вложи очки по строке «Фарм».
2. Возьми Плазменный мультирезак.
3. В отряд возьми палов с пассивками:
   - Начальник рудника — ты добываешь руду на 25% лучше.
   - Лидер лесозаготовок — ты рубишь деревья на 25% лучше.
   - Мотиватор — ты работаешь на 25% быстрее.
4. Надень Пояс для инструментов жителя острова.
5. Для перелётов — Джетрагон.
С палов с пассивкой <a class="psv r-4" data-psv="Щедрость" href="../../passivki/lavish_hospitality/">Щедрость</a> падает в 2 раза больше добычи. <a class="psv r-3" data-psv="Дух радушия" href="../../passivki/service_minded/">Дух радушия</a> — +50%.

## Два пути
### Быстрый путь
1. Сбрось очки на «Рейды».
2. Надень древнюю броню, возьми Дрономёт.
3. Поймай легендарных палов (Джетрагон, Фросталлион, Некромус, Паладиус).
4. Возьми в отряд Силвегиса и Петаллию.
5. Иди: обычные рейды → сложные башни → самые трудные рейды.
### Максимальный путь
1. Выведи каждому бойцу 4 лучшие пассивки.
2. Сделай Пробуждение.
3. Сделай 4 звезды конденсацией (сначала Силвегису и Орсерку).
4. Вложи Души до конца.
5. Собери команду под каждого босса.
